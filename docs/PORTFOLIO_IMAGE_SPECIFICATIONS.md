# Portfolio Image Specifications & File Naming Guide

## Overview
This document provides complete specifications for all portfolio project images, including exact dimensions, composition requirements, and file naming conventions that match the website's data structure.

---

## Technical Specifications

### Universal Requirements
- **Format:** JPG (preferred for photos/mockups), PNG (for transparency needs)
- **Color Space:** sRGB
- **Resolution:** 72 DPI (web optimized)
- **Quality:** 85% (balance between quality and file size)
- **Max File Size:** 500KB per image (compress if needed)

### Image Dimensions

| Image Type | Dimensions | Aspect Ratio | Usage |
|------------|-----------|--------------|-------|
| **Hero/Main Image** | 1200×800px | 3:2 | Bento card background |
| **Gallery Images** | 1600×1000px | 16:10 | Modal gallery |
| **Detail Shots** | 1600×1000px | 16:10 | Modal gallery |
| **Wide Compositions** | 1920×1080px | 16:9 | Full-width spreads |
| **Square Compositions** | 1200×1200px | 1:1 | Social/grid layouts |

## Image Creation Workflow

### 1. PDF to JPG Exports
**Tool:** Adobe Acrobat, Preview (Mac), or PDF export tool

**Steps:**
1. Open PDF in export tool
2. Select "Export to Image"
3. Choose JPG format, 85% quality
4. Set resolution to 150 DPI minimum (will resize down)
5. Export at exact dimensions needed OR larger and resize

### 2. PNG to JPG Conversion
**Tool:** Any image editor (Photoshop, Preview, online converter)

**Steps:**
1. Open PNG file
2. Add white background if transparent
3. Export as JPG, 85% quality
4. Resize to exact specifications

### 3. HTML Email Screenshots
**Tool:** Browser + Developer Tools

**Steps:**
1. Open HTML file in Chrome/Firefox
2. Open Developer Tools (F12)
3. Set viewport to exact width needed
   - Desktop: 1200px width
   - Mobile: 375px width
4. Screenshot full page
5. Crop to specifications

### 4. Composite/Grid Creation
**Tool:** Figma (recommended), Photoshop, or Canva

**Steps:**
1. Create artboard at target dimensions
2. Import all component images
3. Arrange in grid with consistent spacing
4. Add subtle borders/shadows if needed
5. Export as JPG at 85% quality

### 5. Mockup Creation
**Tool:** Smartmockups.com, Placeit.net, or Mockup World PSDs

**Steps:**
1. Choose appropriate mockup template
2. Upload your artwork
3. Adjust positioning/perspective
4. Export at target dimensions
5. Compress to under 500KB if needed

## Compression & Optimization

### Recommended Tools:
- **TinyJPG/TinyPNG** - https://tinyjpg.com (drag & drop compression)
- **ImageOptim** (Mac) - Lossless optimization
- **Squoosh** - https://squoosh.app (Google's web-based tool)
- **JPEGmini** - Smart JPEG compression

### Target File Sizes:
- Hero images (1200×800): 150-300KB
- Gallery images (1600×1000): 200-400KB
- Wide images (1920×1080): 300-500KB

## Quality Checklist

Before uploading each image, verify:

- [ ] Correct filename (lowercase, hyphens, no spaces)
- [ ] Exact dimensions match specification
- [ ] File size under 500KB
- [ ] JPG quality 85% or PNG optimized
- [ ] No watermarks or artifacts
- [ ] Text is legible at thumbnail size
- [ ] Colors accurate to brand
- [ ] Composition follows guidelines
- [ ] Image is sharp and properly focused
- [ ] Located in correct directory
