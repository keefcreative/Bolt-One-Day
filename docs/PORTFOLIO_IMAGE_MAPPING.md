## Export Recommendations

### Image Specifications
- **Hero images:** 1200×800px, JPG, quality 85%
- **Gallery images:** 1600×1000px or native aspect ratio, JPG, quality 85%
- **File naming:** lowercase, hyphens, no spaces

### Suggested Tools
1. **PDF to JPG:** Adobe Acrobat, Preview (Mac), or online converter
2. **PNG to JPG:** Any image editor (maintain quality)
3. **Screenshots:** Browser dev tools for HTML emails, Cleanshot/Snagit
4. **Composites:** Figma, Photoshop, or Canva for grids/layouts
5. **Mockups:** Smartmockups, Placeit for context shots
