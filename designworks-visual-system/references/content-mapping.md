# Content-to-Visual Mapping

A decision framework for choosing the right visual approach for any content. Use this guide to translate messages, themes, and purposes into specific visual treatments.

---

## The Mapping Process

For any piece of content, answer three questions:

1. **What is the primary message?** → Determines symbol category
2. **What emotion should it evoke?** → Determines visual register
3. **Where will it appear?** → Determines format/complexity

---

## Message → Symbol Mapping

### If the content is about...

| Content Theme | Primary Symbols | Scene Template |
|---------------|-----------------|----------------|
| **Process / Methodology** | Grids, golden ratio, sequential nodes | "The System" |
| **Quality / Excellence** | Fibonacci circles, compass arcs, precision marks | "The Craft" |
| **Collaboration / Partnership** | Constellation clusters, connection lines | "The Connection" |
| **Results / Transformation** | Before→after, ascending lines, emergence | "The Breakthrough" |
| **Full-Service / Capabilities** | Orbital paths, multi-scale clusters | "The Overview" |
| **Innovation / New Thinking** | Bezier curves, network nodes, light bursts | "The Breakthrough" variant |
| **Strategy / Planning** | Grid systems, rule of thirds, alignment marks | "The System" variant |
| **Community / Culture** | Dense constellation, multiple node clusters | "The Connection" variant |
| **Growth / Scale** | Fibonacci progression, branching structures | "The Overview" variant |
| **Expertise / Knowledge** | Layered depth, mathematical constructs | "The Craft" variant |

## Emotion → Register Mapping

### If the feeling should be...

| Desired Emotion | Visual Register | Key Adjustments |
|-----------------|-----------------|-----------------|
| **Confident / Authoritative** | Precision & Craft | More grid structure, less movement, cooler tones |
| **Inspiring / Aspirational** | Impact & Purpose | Ascending elements, more green accent, emergence |
| **Exciting / Bold** | Innovation & Edge | More dynamic angles, brighter orange, faster animation |
| **Trustworthy / Reliable** | Precision & Craft | Heavy grid foundation, balanced composition |
| **Forward-thinking** | Innovation & Edge | Network clusters, light bursts, parallax depth |
| **Warm / Approachable** | Balanced blend | Softer node glows, more curved connections |
| **Serious / Important** | Precision dominant | Minimal elements, maximum negative space |
| **Energetic / Dynamic** | Innovation dominant | Multiple moving layers, faster timing |

## Context → Format Mapping

### By Output Type

| Output | Recommended Approach |
|--------|---------------------|
| **Website hero** | Animated, moderate complexity, full scene template |
| **Presentation cover** | Static, minimal, single scene template element |
| **Presentation interior** | Static, very minimal, corner accent only |
| **Social media post** | Static or simple animation, focused composition |
| **Document header** | Static, minimal, horizontal accent |
| **Video intro** | Animated stroke-draw, 3-5 seconds |
| **Email header** | Static, horizontal, very simple |
| **Print cover** | Static, moderate complexity, scene template |
| **Print interior** | Static, minimal accents only |

### By Audience

| Audience | Adjust Toward |
|----------|---------------|
| **C-suite / Executives** | More minimal, Precision register |
| **Creative professionals** | Can be richer, Innovation register |
| **General public** | Cleaner, more obvious symbolism |
| **Technical audience** | Can include more mathematical detail |
| **Prospective clients** | Impact register, transformation symbols |
| **Existing clients** | Connection register, collaboration symbols |

## Decision Trees

### Quick Selection

```
Is the content about RESULTS or TRANSFORMATION?
├─ Yes → Use "The Breakthrough" template, Impact register
└─ No → Continue...

Is the content about HOW WE WORK or PROCESS?
├─ Yes → Use "The System" template, Craft register
└─ No → Continue...

Is the content about RELATIONSHIPS or COLLABORATION?
├─ Yes → Use "The Connection" template, balanced register
└─ No → Continue...

Is the content about CAPABILITIES or OVERVIEW?
├─ Yes → Use "The Overview" template, Innovation register
└─ No → Use "The Craft" template as default
```

### Complexity Selection

```
Where will this appear?
├─ Hero/Cover (high visibility) → Full scene, can animate
├─ Supporting position → Partial scene or accent
└─ Background/Ambient → Minimal accent only

How long will viewer engage?
├─ Glance (<3 seconds) → Immediate recognition needed, simpler
├─ Short read (3-30 seconds) → Can have moderate detail
└─ Extended engagement (>30 seconds) → Can reward inspection
```

## Combination Examples

### Example 1: Case Study Hero

**Content:** Showcasing a successful rebrand project
**Message:** Transformation + Quality
**Emotion:** Confident, Inspiring
**Context:** Website hero, extended engagement

**Visual Approach:**
- Scene: "The Breakthrough" with "The Craft" elements
- Symbols: Before→after framing + golden ratio + emerging forms
- Register: Impact dominant, Craft secondary
- Animation: Stroke-draw reveal of transformation, then settle

### Example 2: Capabilities Deck Cover

**Content:** Full-service agency overview
**Message:** Breadth + Expertise
**Emotion:** Confident, Forward-thinking
**Context:** Presentation cover, C-suite audience

**Visual Approach:**
- Scene: "The Overview" simplified
- Symbols: Orbital paths + constellation cluster (minimal)
- Register: Precision dominant
- Format: Static, 70%+ negative space

### Example 3: Partnership Announcement

**Content:** New strategic partnership
**Message:** Connection + Growth
**Emotion:** Warm, Exciting
**Context:** LinkedIn post, general audience

**Visual Approach:**
- Scene: "The Connection" focused
- Symbols: Two node clusters + connecting lines + subtle glow
- Register: Innovation with warmth
- Format: Static, clean focal point for text overlay

### Example 4: Process Blog Post

**Content:** How we approach brand strategy
**Message:** Methodology + Expertise
**Emotion:** Trustworthy, Authoritative
**Context:** Blog header, creative professionals

**Visual Approach:**
- Scene: "The System"
- Symbols: Grid foundation + sequential nodes + compass arc
- Register: Craft dominant
- Format: Static, horizontal for header, mathematical detail OK

### Example 5: Video Intro

**Content:** Agency showreel opener
**Message:** Excellence + Innovation
**Emotion:** Exciting, Bold
**Context:** Video, 4-second intro

**Visual Approach:**
- Scene: "The Craft" into "The Breakthrough"
- Symbols: Golden ratio draws on → transforms into ascending burst
- Register: Innovation dominant
- Animation: Fast stroke-draw (1.5s) → hold → burst emergence (1s)

## Anti-Patterns

Avoid these common mapping mistakes:

| Mistake | Why It's Wrong | Instead |
|---------|----------------|---------|
| Everything gets "The Overview" | Dilutes meaning, becomes generic | Match scene to specific message |
| Maximum complexity everywhere | Exhausts viewer, loses impact | Reserve complexity for key moments |
| Always Innovation register | Feels relentless, ungrounded | Balance with Craft for credibility |
| Ignoring context | Hero treatment in ambient position | Scale appropriately |
| Literal interpretation | "Partnership" → two hands shaking | Use abstract connection symbols |
| Same visual for different messages | Loses specificity | Vary symbols by content |
