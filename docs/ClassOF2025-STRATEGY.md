// Set deadline
const deadline = new Date('December 31, 2025 23:59:59 GMT');

function updateCountdown() {
  const now = new Date().getTime();
  const distance = deadline - now;
  
  const days = Math.floor(distance / (1000 * 60 * 60 * 24));
  const hours = Math.floor((distance % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
  const minutes = Math.floor((distance % (1000 * 60 * 60)) / (1000 * 60));
  const seconds = Math.floor((distance % (1000 * 60)) / 1000);
  
  // Update DOM
  document.getElementById('days').textContent = days.toString().padStart(2, '0');
  document.getElementById('hours').textContent = hours.toString().padStart(2, '0');
  document.getElementById('minutes').textContent = minutes.toString().padStart(2, '0');
  document.getElementById('seconds').textContent = seconds.toString().padStart(2, '0');
  
  if (distance < 0) {
    // Deadline passed
    document.querySelector('.countdown').innerHTML = '<p>Applications Closed</p>';
  }
}

// Update every second
setInterval(updateCountdown, 1000);

## CONTENT WRITING PRINCIPLES

### Brand Voice Application

**Four Pillars (from Brand Voice Guide):**

1. **HONEST** - Speak plainly, admit limits, state trade-offs
   - Example: "Fair trade-off: You don't get instant 24/7 availability. You do get 48-hour turnaround."

2. **PRINCIPLED** - Frame decisions in values (clarity, impact, fairness)
   - Example: "Good design is how your audience decides to trust you."

3. **HUMAN** - Empathize with pressures, use relatable examples
   - Example: "Your competitor launched last week. You're still waiting on revisions."

4. **BALANCED** - Mix urgency with reassurance, state facts over hype
   - Example: "Lock £999/month now, or pay £1,449/month later. The trade-off is clear."

### Messaging Hierarchy

**Primary Message:** Design velocity as competitive weapon  
**Supporting Messages:**
- Strategic partnership vs transactional service
- Cohort economics align incentives
- Rate lock provides economic certainty
- 48-hour turnaround enables market agility

**Avoid:**
- Superlatives without substance ("revolutionary," "game-changing")
- Vague promises ("We'll help you dominate")
- Pressure tactics ("You'll regret missing this!")
- Corporate jargon ("Leverage synergies")

### Copy Testing Checklist

Before publishing, test copy against these questions:

✓ Would I understand how this makes me more competitive than using a good freelancer?  
✓ Is the mechanism clear (not just the benefit)?  
✓ Are trade-offs stated honestly?  
✓ Would I believe this if a competitor said it?  
✓ Does this sound like a human talking, or marketing speak?  
✓ Is there a clear next action?  
✓ Does the urgency come from facts, not pressure?
