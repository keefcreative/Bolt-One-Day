# Visual World

The vocabulary of objects, symbols, and concepts that exist within the DesignWorks Bureau visual language. This document defines **what** can appear — the aesthetic guidelines define **how** it looks.

## Core Philosophy

DesignWorks Bureau visuals embody two metaphors:

1. **The Connector** — Networks, relationships, bridges, systems thinking
2. **The Craftsperson** — Tools, precision, intentional making, refinement

Combined, these create a visual language of **precise connections** — systematic, purposeful, and elegantly constructed.

These represent design methodology, systematic thinking, and craft mastery.

| Symbol | Meaning | Use When |
|--------|---------|----------|

| Geometric progressions | Scalable thinking | Growth, expansion, scaling |

| Symbol | Meaning | Use When |

## Forbidden Elements

These elements should **never** appear in DesignWorks visuals:

| Forbidden | Reason | Alternative |
|-----------|--------|-------------|
| Abstract human figures | Humans must be real (photography) | Use implied presence via tools/objects |
| Cartoon/illustrated people | Brand authenticity | Photography for people |
| Dense, cluttered compositions | Conflicts with minimal precision | Simplify, use negative space |
| Filled shapes (solid areas) | Brand uses stroke-based line art | Outline everything |
| Thick strokes (>2px) | Feels heavy, imprecise | Keep at 1px, max 1.5px |
| Trendy effects (gradients, shadows) | Dates quickly | Timeless line art |
| Stock imagery clichés | Handshakes, lightbulbs, etc. | Use brand symbol vocabulary |
| Excessive color | Brand is primarily monochromatic + accent | Restrain to palette |

## Composition Principles

### Density: Minimal

Every element must earn its place. If it doesn't serve a purpose, remove it.

**Target:** 60-70% negative space in any composition

### Placement: Intentional

Elements should align to mathematical principles:
- Place focal points at rule-of-thirds intersections
- Use golden ratio for size relationships
- Maintain consistent margins (Swiss grid principles)

### Layering: Purposeful Depth

When using layers:
- Maximum 3 depth layers
- Back layer: very subtle (blur, low opacity)
- Mid layer: supporting context
- Front layer: primary focus

### Balance: Asymmetric Harmony

Avoid perfect symmetry. Instead:
- Use weighted balance (larger element + smaller counterweight)
- Constellation clusters naturally create asymmetric balance
- Mathematical constructs can be off-center

## Emotional Registers

How to express different brand values through visual choices:

### Precision & Craft
- **Primary symbols:** Grids, golden ratio, rulers, crosshairs
- **Composition:** Extra negative space, perfect alignment
- **Color:** Predominantly neutral strokes, selective orange accent
- **Animation:** Slow, deliberate stroke-drawing

### Impact & Purpose
- **Primary symbols:** Transformation elements, ripples, ascending lines
- **Composition:** Dynamic movement suggested through angles
- **Color:** Can use green (#16a34a) for impact/social themes
- **Animation:** Reveals, emergence, growth motion

### Innovation & Edge
- **Primary symbols:** Network clusters, Bezier curves, light bursts
- **Composition:** More dynamic, breaking grid slightly
- **Color:** Brighter orange accents, more contrast
- **Animation:** Faster timing, more dramatic parallax

### Combination (Most Content)

Most content will need all three. Layer them:
1. Base: Grid/mathematical structure (Craft)
2. Middle: Network/connection elements (Innovation)
3. Accent: Transformation indicator (Impact)

## Implied Human Presence

Since abstract humans are forbidden, suggest human presence through:

- **Tools in use** — A compass mid-arc implies the hand guiding it
- **Gesture traces** — A sketched line implies the designer's movement
- **Interaction points** — Nodes that suggest someone clicked/chose
- **Scale references** — Objects at human scale imply the user
- **Collaborative marks** — Multiple connection points suggest teamwork

Never show the person. Show the evidence of their craft.
