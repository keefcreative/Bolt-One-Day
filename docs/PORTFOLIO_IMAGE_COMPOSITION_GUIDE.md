## Composition Principles (From Top Portfolios)

### 1. Hero Image Compositions
- **Clean background** - solid colour or subtle gradient
- **Product/deliverable in context** - mockup showing real-world application
- **Strong lighting** - professional shadows and highlights
- **Minimal clutter** - one focal point per image

### 2. Brand Identity Gallery Images
Based on successful Behance projects, include:

| Image Type | Purpose | Example Composition |
|------------|---------|---------------------|
| **Logo Presentation** | Show logo on clean background | Logo centered, plenty of whitespace, maybe subtle brand pattern |
| **Stationery Suite** | Business collateral | Angled stack of business cards, letterhead, envelope |
| **Application Mockup** | Real-world context | Logo on building signage, vehicle, or merchandise |
| **Guidelines Spread** | Process/system | Two-page spread from brand guidelines document |
| **Before/After** | Transformation | Side-by-side comparison (subtle, not heavy-handed) |

### 3. Multi-Channel Campaign Gallery
For projects like your Black Friday campaign:

| Image Type | Composition Approach |
|------------|----------------------|
| **Overview Hero** | All channels arranged in grid/collage |
| **Web Banners** | Desktop + mobile shown together, device frames |
| **Social Suite** | 3-4 posts arranged in row or grid |
| **Email Sequence** | 3 emails stacked or cascaded |
| **Print Materials** | Large format shown with scale reference |

### 4. Email Design Portfolio Images
- **Desktop view** - email in browser window mockup
- **Mobile responsive** - phone mockup showing same email
- **Code peek** - subtle code editor in background (shows technical skill)
- **Before/after** - if redesigning existing templates
- **Multi-device** - laptop + phone + tablet showing responsive design

## Quick Composition Tips

### DO:
✅ Use consistent lighting direction across all images
✅ Maintain colour consistency with brand palette
✅ Include context/scale references for print work
✅ Show process (sketches, iterations) alongside finals
✅ Use clean, uncluttered backgrounds
✅ Ensure text is readable at portfolio thumbnail size

### DON'T:
❌ Overcrowd compositions with too many elements
❌ Use harsh drop shadows or outdated effects
❌ Mix different mockup styles in one project
❌ Show low-resolution or pixelated work
❌ Include watermarked stock images
❌ Use busy backgrounds that compete with the work
